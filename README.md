# Лабораторная работа №1: анализ землетрясений USGS

**Участники:** Марюшкина Софья, Чуева Арина — поток 1.3.

Основной результат работы — самостоятельный блокнот [lab1_usgs.ipynb](lab1_usgs.ipynb). В нём последовательно представлены получение событий из [USGS Earthquake Catalog API](https://earthquake.usgs.gov/fdsnws/event/1/1), преобразование ответа GeoJSON, сохранение и догрузка в SQLite, а также аналитические запросы через pandas и SQLAlchemy.

## Данные и хранение

Выборка охватывает землетрясения магнитудой от 2,5 за 1–14 января 2025 года в UTC. Загрузка разделена на два недельных интервала; повторная запись первого интервала используется для проверки отсутствия дублей. При большом ответе API предусмотрена пагинация.

Таблица SQLite `earthquakes` хранит идентификатор USGS, время события и обновления, магнитуду, глубину, координаты, место, сеть, статус, флаг `tsunami`, значимость и ссылку на событие. `event_id` служит первичным ключом. Новые события вставляются, а существующие обновляются при более позднем времени обновления источника. Файл базы создаётся локально в `data/earthquakes.sqlite`.

## Аналитические запросы

Каждая из шести агрегаций выполнена отдельно в pandas и SQLAlchemy. В конце блокнота результаты двух способов сопоставляются и сохраняются в CSV.

| № | Измерение | Показатели |
|---|---|---|
| 1 | День UTC | количество, средняя и максимальная магнитуда |
| 2 | Диапазон магнитуды | количество, средняя глубина |
| 3 | Диапазон глубины | количество, средняя магнитуда |
| 4 | Сеть каталога | количество, средняя и максимальная магнитуда |
| 5 | Час UTC | количество, средняя магнитуда |
| 6 | Флаг `tsunami` | количество, средняя магнитуда и значимость |

Параметры эксперимента, численные результаты и ограничения анализа приведены в [отчёте](REPORT.md). Зависимости Python перечислены в [requirements.txt](requirements.txt). База данных и производные CSV исключены из версионного контроля.
