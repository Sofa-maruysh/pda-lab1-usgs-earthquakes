# Лабораторная работа №1: землетрясения USGS

**Участники:** Марюшкина Софья и Чуева Арина, поток 1.3.

Источник данных — [USGS Earthquake Catalog API](https://earthquake.usgs.gov/fdsnws/event/1/1), согласованный для этой лабораторной. Работа выполняет три пункта задания: сбор данных с веб-ресурса, хранение и догрузку в SQLite, шесть разных агрегаций двумя способами — pandas и SQLAlchemy.

## Быстрый запуск

Нужен Python 3.10+ и доступ в интернет. Команды выполняются из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python usgs_lab1.py sync --start 2025-01-01 --end 2025-01-08 --min-magnitude 2.5
python usgs_lab1.py sync --start 2025-01-08 --end 2025-01-15 --min-magnitude 2.5
python usgs_lab1.py analyze
```

На Linux/macOS вместо активации PowerShell используйте `source .venv/bin/activate`. Конец периода не включается; все даты и часы в UTC. Чтобы обновить уже загруженные события и проверить отсутствие дублей, повторите любую команду `sync` с теми же параметрами.

База создаётся в `data/earthquakes.sqlite`, таблицы результатов — в `results/`. Эти файлы не коммитятся, так как их можно воспроизвести командами выше. Изменить пути можно параметрами `--db` и `--output`; размер страницы API — параметром `--page-size` (1–20000). Для запуска в Colab откройте [lab1_usgs.ipynb](lab1_usgs.ipynb).

## Что делает программа

1. Запрашивает у USGS события типа `earthquake` в формате GeoJSON; если ответ занимает несколько страниц, обходит их по `offset`.
2. Преобразует время Unix в UTC, координаты GeoJSON — в широту, долготу и глубину, сохраняет значимые поля в SQLite.
3. Использует `event_id` как первичный ключ. При повторной загрузке обновляет запись только если у USGS выросло поле `updated`; другие записи остаются без изменений.
4. Строит шесть агрегаций и сохраняет для каждой два CSV: суффиксы `_sql` и `_pandas`.

| № | Вопрос | Группировка и показатели |
|---|---|---|
| 1 | Как менялась активность по дням? | день UTC, количество, средняя и максимальная магнитуда |
| 2 | Как распределены магнитуды? | диапазон магнитуды, количество, средняя глубина |
| 3 | Как распределены глубины? | мелкие, промежуточные, глубокие; количество и средняя магнитуда |
| 4 | Какие сети сообщили события? | код сети, количество, средняя и максимальная магнитуда |
| 5 | Как события распределены по времени суток? | час UTC, количество, средняя магнитуда |
| 6 | Чем отличаются события с флагом tsunami? | флаг, количество, средняя магнитуда и значимость |

Код сети `net` отражает источник записи в каталоге USGS, а не страну события. Флаг `tsunami` — атрибут записи USGS, его нельзя трактовать как подтверждённое цунами.
