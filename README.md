# Сбор и агрегация данных о землетрясениях

Лабораторная работа №1. Марюшкина Софья, Чуева Арина — поток 1.3.

В работе реализованы сбор данных с [USGS Earthquake Catalog](https://earthquake.usgs.gov/fdsnws/event/1/), их хранение в SQLite с возможностью догрузки и шесть запросов для агрегации. Сбор выполняется библиотекой Scrapy через API USGS. Для работы с базой используется SQLAlchemy, для обработки данных — pandas.

## Используемые технологии

- Python 3.12
- Scrapy
- SQLAlchemy
- SQLite
- pandas

## Собираемые данные

Одна строка таблицы `earthquakes` соответствует одному событию USGS.

| Поле | Описание |
|---|---|
| `event_id` | Уникальный ID события USGS, первичный ключ |
| `occurred_at` | Дата и время события в UTC |
| `updated_ms` | Время последнего обновления записи в USGS, миллисекунды Unix |
| `magnitude` | Магнитуда |
| `depth_km` | Глубина, км |
| `latitude`, `longitude` | Координаты |
| `place` | Описание места |
| `network` | Код сети, предоставившей запись |
| `status` | Статус проверки события |
| `tsunami` | Флаг tsunami из каталога USGS |
| `significance` | Показатель значимости события USGS |
| `url` | Ссылка на событие |

## Сбор и догрузка

Scrapy запрашивает данные в формате GeoJSON и обрабатывает ответ: свойства события и координаты преобразуются в поля таблицы. Большая выборка загружается по страницам с параметрами `limit` и `offset`. Записи без ID, магнитуды, времени или координат пропускаются и учитываются в статистике загрузки.

По умолчанию выбран период **1–14 января 2025 года**, магнитуда **от 2,5**. Начало периода включено, конец не включён; все даты относятся к UTC.

При сохранении проверяется `event_id`. Новое событие добавляется, существующее обновляется только при более свежем `updated_ms`. Повторная загрузка не создаёт дубликатов. Для догрузки указывается следующий период.

Зависимости:

```bash
python -m pip install -r requirements.txt
```

Сбор выбранного по умолчанию периода:

```bash
python -m scrapy crawl earthquakes
```

Пример последовательной загрузки двух недель:

```bash
python -m scrapy crawl earthquakes -a start=2025-01-01 -a end=2025-01-08
python -m scrapy crawl earthquakes -a start=2025-01-08 -a end=2025-01-15
```

Порог магнитуды задаётся параметром `-a min_magnitude=2.5`.

## Агрегация данных

В `analysis.py` каждый запрос реализован двумя способами: pandas группирует строки, прочитанные из SQLite, а SQLAlchemy формирует SQL-запрос, который выполняется в базе.

| № | Группировка | Рассчитываемые показатели |
|---|---|---|
| 1 | День UTC | Количество событий, средняя и максимальная магнитуда |
| 2 | Диапазон магнитуды | Количество событий, средняя глубина |
| 3 | Диапазон глубины | Количество событий, средняя магнитуда |
| 4 | Сеть каталога | Количество событий, средняя и максимальная магнитуда |
| 5 | Час UTC | Количество событий, средняя магнитуда |
| 6 | Флаг tsunami | Количество событий, средняя магнитуда и значимость |

Диапазоны магнитуды: `<3`, `3–<4`, `4–<5`, `5–<6`, `≥6`. Диапазоны глубины: `<70`, `70–<300`, `≥300` км. Неизвестная глубина исключается из группировки по глубине.

```bash
python analysis.py
```

Результаты выводятся в консоль и сохраняются в 12 CSV-файлов: по два на каждый запрос. Соответствующие таблицы pandas и SQLAlchemy автоматически сравниваются с допуском `1e-8` для чисел с плавающей точкой.

## Результаты

Проверка на данных USGS от 5 октября 2026 года, период событий 1–14 января 2025 года:

| Этап | Получено | Добавлено | Всего строк в базе |
|---|---:|---:|---:|
| Загрузка 1–7 января | 585 | 585 | 585 |
| Повтор 1–7 января | 585 | 0 | 585 |
| Догрузка 8–14 января | 516 | 516 | 1101 |

По результатам агрегаций:

- Больше всего событий за день: **107**, 7 января. Максимальная магнитуда этого дня — **7,1**.
- Самая многочисленная группа по магнитуде: **4–<5**, **659** событий.
- По глубине: **891** событие менее 70 км, **169** — от 70 до 300 км, **41** — от 300 км.
- Больше всего записей предоставила сеть `us`: **894**.
- Наиболее частый час UTC в выборке — **01:00–01:59**, **67** событий.
- Флаг `tsunami=1` установлен у **2** событий, `tsunami=0` — у **1099**. Этот флаг сам по себе не подтверждает возникновение цунами.

Результаты всех шести запросов совпали в pandas и SQLAlchemy. Данные сохранены в SQLite, повторная загрузка не создаёт дубли, догрузка увеличивает число записей. Выводы относятся к выбранному периоду и порогу магнитуды; каталог USGS может уточняться, поэтому результаты последующих загрузок могут отличаться.
